## What's new

**If you installed 1.2.0 and the window stays black**: download and install this version by hand (the file for your system is below). From here on, updates show up even if the window doesn't load.

- **New updater**: when there's a new version, Vexcast opens a small update window on start with what's new, the download progress and "Update now", "Later" and "Skip this version". It works on its own, even if the main window fails to load.
- **Fixed**: the main window stayed black on start in 1.2.0.

### Also in 1.2

- **Linux AppImage** with the OBS engine inside, for any distro, and it updates itself.
- **Intel Macs** are supported.
- **Automatic setup** (Settings › Output › Streaming): measures your upload and recommends bitrate, resolution and FPS for your destinations.
- **Twitch clips** from the command palette or a macro (link Twitch again to allow it).
- **Summary when the stream ends**: viewers, chat, follows, subs and dropped frames.
- **System checks**: warns about the macOS screen recording permission, Wayland sessions or an engine that didn't start.
- **Third-party OBS plugins** (Settings › Advanced), off by default. A plugin that crashes Vexcast is turned off on the next start.
